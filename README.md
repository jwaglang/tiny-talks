# Tiny Talks Journal (alpha)

A single-page app for working through Tiny Talks line by line:
Listen, Read, Write, Speak, then Test & Annotate.

- Everything is saved in the learner's own browser (IndexedDB). Use Settings > Download backup to move it.
- Teachers can make line-timed audio with ElevenLabs (key stays in the teacher's browser), then "Share with a student" to send a talk file with the audio inside.
- "Download the note" exports an Obsidian note in the Tiny Talk format, with Osmosis cards.
